🩸 Blood Bank Management System

A Blood Bank Management System developed using Python and Django to manage blood donors, blood stock, and blood requests efficiently. The system helps blood banks maintain accurate records, monitor blood availability, and streamline the process of blood donation and distribution.

Features

* User Authentication
* Donor Registration & Management
* Blood Group Management
* Blood Stock Tracking
* Blood Donation Records
* Blood Request Management
* View Available Blood Groups
* User-friendly web interface

Tech Stack

Backend: Python, Django
Frontend: HTML, CSS, Bootstrap
Database: SQLite
